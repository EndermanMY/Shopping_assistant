# 购物小助手 v0.1.2 · Windows x64

本次发布包含 [Issue #1](https://github.com/EndermanMY/shopping-assistant/issues/1) 对应的独立浏览器访问修复，以及未发布的任务重置、提交取证和速度优化。

## 安装与升级

下载完整 Windows x64 ZIP，全部解压，双击 `start.bat`。默认 `http://127.0.0.1:18765/`，本机终端显示首次生成的控制台访问码。无需安装 Python、Node.js 或本机 Chrome。发布包没有预置账号，首次使用需自行登录京东。

先停止旧服务并备份旧 `data/`；仅在自己的电脑上迁移 `assistant.db`、`access.json`、`browser/`、需要的截图及 `browser-network.json`，保留新版的 `data/browsers/`。不要把个人数据上传到 GitHub。数据库自动升级，旧任务不会自动启用。

## 主要变化

- 默认改为程序自带固定版本浏览器普通启动，再由本机回环 CDP 接管。只使用应用专用目录，不连接本机 Chrome、不复制本机 Cookie。浏览器退出或服务结束会清理属于自己的浏览器进程树。
- 默认跟随系统代理，不修改系统网络；若你的代理出口引发访问异常，可在停止浏览器后运行 `powershell -ExecutionPolicy Bypass -File configure-browser.ps1 -Network direct`，仅让助手直连。恢复为 `-Network system`。用户自行选择，不预置发布者的个人网络配置。
- 检测页面异常、人工验证、访问频繁、主导航或下单 API 的 403/429 后暂停，停止反复解析、登录或查询。冷却到期不会自动继续下单。平台限制不能保证永久消除。
- 结果不明任务在列表与详情显示重置入口；重置前要求用户确认未下单，并再核验订单列表。有明确或 API 候选订单号时不允许清空记录。
- 提交时被动读取当前页面下单 API，持久保存返回的候选订单号；控制台显示待核验号码。它必须与商品、数量、金额和订单状态核验一致，不将 HTTP 200 或候选号码直接当作成功。
- 接口明确拒单时提前结束付款页空等；结果不明时不重复提交。新增响应/取证耗时日志，不记录签名 URL、Cookie 或请求正文。
- 减少商品详情加载等待和购物车整页刷新；保留场次时间、金额、数量及精确 SKU 的提交前校验。

## 隐私与验证

源码和 ZIP 均排除登录目录、Cookie、访问码、任务数据库、地址、个人订单、日志、截图和诊断资料。ZIP 中 `data/` 只含原始浏览器运行文件；运行后才在本机生成私人数据。

发布前完整 **219 项**回归通过（353.15 秒，1 条既有依赖弃用警告）；本版包括默认启动方式及发布隐私检查。编译 EXE 另外以空白临时数据验证启动、认证、静态资源、独立浏览器打开与关闭。具体 ZIP 校验和内嵌模块隐私扫描见发布附件 `v0.1.2-validation.json`。

真实浏览恢复已由用户确认，真实只读结算 API 已校准；目标限定版的真实 API 下单没有验收。v0.1.2 的生产提交方式仍为页面提交配合 API 响应取证；API 下单作为独立分支预发布，不混入本版。
