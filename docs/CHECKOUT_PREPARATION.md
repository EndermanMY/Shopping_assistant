# 提前准备结算，按实际开始时间提交

实际开始 `T = scheduled_at - advance_ms`。结算准备从 `T - 20 秒` 开始，目标在 `T - 10 秒` 前完成；到 `T` 才允许提交。提前量仍是毫秒，持续时间仍从 `T` 起算。

例如所填时间 10:00:00、提前量 600 毫秒：09:59:39.400 开始准备，目标 09:59:49.400 前完成，09:59:59.400 开始提交。提前准备包括购物车勾选、进入结算、核对准确 SKU、数量、地址、含运费金额及手动付款方式；不点击提交、进入支付或创建订单。

普通现货可提前进入结算等待。未开售商品若购物车仍不能勾选、结算入口不可用或价格待公布，会保留购物车等待，到点再检查；不强行绕过平台限制。网络慢、页面变化或任务启动太晚时不能保证提前十秒完成，日志明确说明未就绪或晚于目标。

## 到点复核

完整 SKU 核验前记录结算业务值，核验后按稳定业务值保存证据。比较商品链接/标题、数量、选中地址、金额、付款选择及 SKU 导航回调，忽略高亮、样式、追踪参数和无关的 React 回调。信息与配置一致、证据未超过 60 秒时复用 SKU 身份，不重复打开详情；核对过程中业务内容变化时最多核对两次，仍变化则暂停并显示变化区域。

关键业务内容或配置改变时重新完整核验；默认模式价格超限、数量/地址/规格不符仍暂停。提交按钮的忙碌显示不当作商品变化，但可见、可用及手动付款入口仍独立定位。主分支仅页面点击提交，不提供 API 直调开关。

新状态 `preparing_checkout` 表示结算准备，仍可停止。准备和等待期间不写提交意图；真正提交前才持久化意图。服务重启后的恢复仍先核验历史提交，不利用缓存重试下单。

v0.1.3-dev 可在每个任务中选择“无视价格下单”，默认关闭。开启后提前核验及提交都跳过应付价格与预算上限；商品、数量、地址、付款方式仍完整检查。价格变化不会单独使已核对的商品证据失效；改变该选项会使旧证据失效。它不能解除京东禁用的购物车勾选控件，不能保证开售前可进入结算；平台仍锁定时继续等待解锁。

## 验证边界

模拟时间覆盖不同毫秒提前量、提前十秒完成的目标、锁定回退及准备中停止。离线浏览器覆盖主分支页面提交：首次 SKU 核验发生在开始前，到点不再次打开商品详情；改价、改数量、改地址、改 SKU、改付款方式及仅修改商品点击处理器均使旧证据失效。模拟成功不代表京东真实场次成功，也不承诺固定毫秒耗时。

“无需条件核对模式”则跳过预约资格、商品、数量、地址及金额核对，不建立或复核结算业务证据；按页面现状仅提交一次。定时、停止、持久提交记录和手动付款保持生效。结果只采用本次响应或付款页的订单号，明确标注条件未核对。
