# v0.2.0-api.2 · 提前结算准备（本地测试版）

本版将原来开抢后进行的购物车勾选、结算与完整核验前置。实际开始为所填时间减去毫秒提前量；提前 20 秒开始准备，目标提前 10 秒完成，到点快速复核后提交。普通页面提交和 API 实验提交均适用。

未解锁、价格待公布等无法预先完成的商品继续在购物车等候，到点检查。结算页面发生变化时重新核验，保留金额、规格、数量、地址、付款方式、截止时间和重复提交保护。API 动态参数仍在提交阶段生成。

完整解压后运行 `start.bat`，默认 `http://127.0.0.1:18766/`，私人数据默认保存在本包的 `data-api/`。发布 ZIP 不含登录、Cookie、访问码、任务、订单或截图。原测试资料如需沿用，仅在本机通过 `SHOPPING_DATA_DIR` 指向旧目录，勿复制进待上传的 ZIP；不要同时运行两个服务访问同一数据目录。

查看 [提前准备说明](CHECKOUT_PREPARATION.md) 了解时间示例及验证边界。真实京东抢购由用户测试，本轮不执行真实订单，也不自动启用现有任务。
