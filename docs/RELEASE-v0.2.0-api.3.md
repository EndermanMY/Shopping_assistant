# v0.2.0-api.3 · 无视价格下单（本地测试版）

创建或修改任务时可勾选“无视价格下单”，默认关闭，旧任务也保持关闭。开启后最高金额输入禁用，未知应付价格、价格高于旧预算不再拦截页面或 API 提交；可能按高于预期的价格生成待付款订单，付款仍由用户手动完成。

继续核对精确 SKU、数量、地址、扫码付款方式、实际开始及截止时间，并保留持久提交意图和未知结果不重试保护。只有唯一新增订单与付款流程证据符合时才输出成功；金额读不到时显示“金额以京东订单为准”。关闭开关后必须填写预算，并重新启用金额检查。

保留 v0.2.0-api.2 的提前准备：实际开始前 20 秒开始结算核对，目标提前 10 秒就绪，按用户填写的毫秒提前量到点提交。无视价格可使已能进入结算但价格未知的商品提前准备；京东禁用的勾选框仍须等待平台解锁。

完整解压后运行 `start.bat`，默认 `http://127.0.0.1:18766/`。私人数据默认位于本包 `data-api/`，发布 ZIP 不带登录、Cookie、访问码、任务、订单或截图；如需沿用旧数据，只在本机用 `SHOPPING_DATA_DIR` 指向原目录，不能将私人目录复制到待分发 ZIP。不要让两个服务同时访问同一数据目录。

本轮使用离线模拟验证，真实京东订单由用户复测；不自动启用任何现有任务或替用户下单。
