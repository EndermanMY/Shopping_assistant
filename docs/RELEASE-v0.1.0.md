# 购物小助手 v0.1.0 · Windows x64

首个本地便携版本。解压完整文件夹后，双击 `start.bat` 或 `ShoppingAssistant.exe`。无需另装 Python、Node.js 或 Chromium；请保留 `_internal` 和 `data/browsers`，不要只复制 EXE。

终端显示控制台地址和首次随机生成的访问码。打开 `http://127.0.0.1:8765/`，输入访问码，然后在应用专用 Chromium 中登录京东。关闭启动窗口会停止执行。端口已被另一实例占用时，新实例会退出，避免影响已有任务。

数据保存在 EXE 同目录 `data/`，请解压到普通可写目录，不要在压缩包里直接运行。发布包仅含全新浏览器二进制；不含开发电脑的账号、登录态、任务、订单、地址、访问码或截图。首次使用需要重新登录、配置和启用任务。

## 本版行为

- 京东个人单账号、单件购买；电脑执行，同一 Wi-Fi 下可用 iPhone 控制。
- 精确识别 SKU 和规格；预约/开抢提醒分别识别；按北京时间单场执行。
- 核对商品、数量、选中地址和含运费总额后，仅提交一次。
- 新版结算选择微信扫码手动付款，进入扫码支付后关闭支付弹窗；关闭支付流程保留订单，不点击“取消订单”。页面结构不匹配会留下单独的支付步骤状态。
- 取得明确的新订单号，且商品、数量、金额与待付款状态匹配，即显示“锁单成功”。支付退出步骤未确认，不抹去已创建订单的事实。
- 未知结果只核验，不重复提交；不自动付款，不使用白条或银行卡扣款。
- 京东付款倒计时到期可能自动取消订单。“锁单成功”记录创建结果，不表示永久保留库存。

## 手机连接

电脑和 iPhone 接入同一 Wi-Fi，使用工作台“手机连接”显示的地址和访问码。若 Windows 阻止连接，在现有专用网络下以管理员身份运行 `enable-lan.ps1`；只开放本地子网、物理网卡、当前助手 EXE 和所用端口。若存在旧安装规则，脚本会要求检查，不会覆盖其他安装的规则。

## 验收范围

历史实测已创建普通现货未付款订单，核对 SKU、数量、金额与待付款状态；真实账号及订单证据仅留在本机，不随公开源码或发布包提供。自动退出支付分支以模拟浏览器验证，不能说成重新完成了一笔真实下单。

## 重新构建

源码工作区准备 Python 3.12、Node.js，运行 `install.ps1` 后运行 `build-release.ps1`。脚本执行构建及测试，固定构建工具版本，收集许可证，按允许列表打包全新浏览器，生成 ZIP 和 SHA-256 清单。构建方式参考 [Playwright 官方说明](https://playwright.dev/python/docs/library#pyinstaller) 与 [PyInstaller 文档](https://pyinstaller.org/en/stable/usage.html)。

此版本尚未做代码签名。第三方许可证保存在 `licenses/`、Chromium 目录及 Playwright 运行时目录中。
